## **Quick Start: Google Cloud Shell Setup**

Follow these steps to prepare your environment for the course:

1.  **Open Google Cloud Shell:**
    *   Go to the [Google Cloud Console](https://console.cloud.google.com/).
    *   Click the **Activate Cloud Shell** button (the terminal icon) in the top-right corner of the console.

2.  **Download and Run the Setup Script:**
    Once Cloud Shell is open, paste and run these commands one by one:

    ```bash
    # Download the setup script
    curl -O https://raw.githubusercontent.com/andreamartelli/genkit-course/main/setup.sh

    # Make the script executable
    chmod +x setup.sh

    # Run the setup script
    ./setup.sh
    ```

Follow the prompts from the script. It will guide you through setting up your Google Cloud project, enabling APIs, granting roles, and installing all necessary tools and code.
